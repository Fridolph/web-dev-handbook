# 学习自测：模型离线指标很好，上线却不灵，怎么排查？

> 📚 参考：[AI / ML / DL / LLM 的层级与评估](/概念与原理/17ai/s_ai_32-ai_ml_dl_llm) | [过拟合与正则化](/概念与原理/17ai/s_ai_14-overfitting_regularization) | [模型幻觉](/概念与原理/17ai/s_ai_20-hallucination)

**场景**：图片分类模型在测试集上准确率 95%，上线一周，用户反馈「经常认错」。老板问：到底是模型不行，还是我们评估错了？

**考察点**：泛化与分布变化、捷径学习、数据泄漏、指标与业务目标的关系、置信度误读。

::: details

## 核心回答

先分清两件事：**离线指标本身是虚高的**，还是**线上场景超出了训练覆盖范围**。常见原因有五类：

| 原因 | 表现 | 怎么发现 |
| --- | --- | --- |
| 分布变化 | 线上输入与训练集差别大（背景、设备、光线、措辞） | 按场景/设备/用户分层看指标，而不是只看总体 |
| 捷径学习 / 虚假相关 | 模型抓了背景、水印、模板句等不可靠线索 | 做对照实验：只换背景/只改措辞，看结果是否崩 |
| 数据泄漏 | 训练集和测试集同源（相邻帧、同一用户、同一次会话） | 检查划分单位；按时间或用户切分重测 |
| 指标错位 | 总体准确率高，但关键类别召回低；平均分掩盖长尾 | 看混淆矩阵、分场景指标，别只看总分 |
| 置信度误读 | 把「95%」当成现实正确率，阈值也照搬 | 用线上数据重画阈值曲线，按业务代价选阈值 |

## 排查顺序

1. **先复现**：拿线上真实失败样本回放，确认不是个案。
2. **分层看指标**：按场景、类别、设备、用户切，找指标在哪一层塌了。
3. **看失败样本**：人眼过一遍，判断是「没学会」还是「学偏了」。
4. **做对照实验**：只换一个变量（背景、措辞、输入长度），验证是否依赖错误线索。
5. **查划分与泄漏**：划分单位与真实使用场景一致吗？有没有同源数据混入？
6. **小流量 + 监控**：上线先灰度，记录失败率与失败类型，别等用户投诉。

## 面试回答要点

- 一句话：**离线好线上差，先怀疑评估，再怀疑模型**。
- 能说出三类典型原因：分布变化、捷径学习、数据泄漏。
- 知道「高分 / 高置信度 ≠ 业务正确」，阈值要按业务代价重新定。
- 能给出可执行的排查动作：分层指标 → 失败样本 → 对照实验 → 灰度监控。
